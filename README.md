# Noneteco Workstation

Интерактивная HTML-библиотека для репетитора английского языка (с двуязычным интерфейсом **RU / EN**).

## Возможности
- **Загрузка HTML в один клик**: перетащите `.html` файлы прямо в окно браузера, вставьте HTML-код из буфера обмена или положите файлы в папку `library/drop/` на GitHub.
- **Теги и навигация**: фильтруйте инструменты по тегам (`#Grammar`, `#Vocabulary`, `#Speaking`, `#B1`, `#Teacher Key` и др.), делитесь ссылками на подборку по тегу (`?tags=...`) и переходите к следующему файлу с тем же тегом прямо из рабочего окна.
- **Пароли на файлы и бандлы**: защита шифрованием **PBKDF2 + AES-256-GCM** — содержимое закрытых HTML-файлов зашифровано даже в публичном репозитории. (Для демо-файла *Past Simple vs Past Perfect* пароль: `noneteco`).
- **Бандлы (наборы работ)**: объединяйте упражнения в последовательность для ученика, добавляйте приветствие и пароль, и отправляйте тремя способами:
  1. Постоянная ссылка (`?bundle=...`)
  2. Мгновенная автономная ссылка (`#share=...`) со сжатием и шифрованием прямо в URL
  3. Скачивание одного автономного `.html`-файла для отправки в Telegram / WhatsApp (работает даже офлайн!).
- **Инструменты урока прямо в окне**: таймер со звуковым сигналом, заметки репетитора к каждому файлу, живой редактор HTML-кода, проверка вида на телефоне/планшете и полноэкранный «Режим урока».

## Как включить постоянную ссылку 24/7 на GitHub Pages
1. Откройте репозиторий **Nastdm/noneteco_workstation** на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. После объединения ветки с `main` сайт автоматически появится по адресу:
   `https://nastdm.github.io/noneteco_workstation/`

---

## Локальный запуск (Full-stack сервер)
```bash
npm install
npm run dev
```
Откройте `http://localhost:3000` — в серверном режиме все файлы, теги, пароли, заметки и бандлы сразу сохраняются в папке `library/`.
